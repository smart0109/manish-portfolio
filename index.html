Systems Built

What I've built, from scratch

I don't outsource the infrastructure. These are production systems I personally designed, coded, and operate. They run the revenue and GTM engine end to end.

Functions typically split across a VP RevOps, a Head of Data, and a Marketing Ops team, built and run by one person.
CC

Command Center

Multi-brand prospect operations platform

A CRM-grade operations platform running all four portfolio companies (Cadient, Vorro, CV3, RevEngineer) on one system, built on a REST API with a MongoDB backend. Serves every prospect, message, and asset across the business.

  • ICP scoring engine that tiers every prospect (A/B/C/DQ) and drives campaign targeting
  • Bulk operations pipeline that updates thousands of records per run across brands
  • Per-brand data partitioning, asset linking (case studies, videos, one-pagers), audit trail
PythonMongoDB REST APISQLite / WAL
OB

Social Selling Outbound Engine

AI-driven prospecting & outreach pipeline

An end-to-end outbound system: find the right prospects, enrich them, score them, and message them with AI-personalized, multi-stage campaigns. Compliance is built in, not bolted on.

  • 5-actor LinkedIn intelligence stack: profile enrichment, ATS detection, activity signals, intent discovery, company data
  • 4-step enrichment waterfall (email/contact resolution) that only pays for data no cache already has
  • GPT-4o/GPT-5-personalized 5-stage message sequences on a tested psychological framework, with an automated QA gate enforcing CAN-SPAM and suppression rules before anything sends
ApifyOpenAI GPT-4o/GPT-5 EvabootApollo.io Gmail API
SB

Second Brain

AI meeting copilot & personal knowledge system

A hosted AI copilot that sits across my calendar, email, and CRM. It captures meeting context, consolidates notes, and carries durable memory forward so nothing gets re-explained twice.

  • Google Calendar + Gmail integrated via OAuth for live meeting prep and follow-up
  • Zoho CRM integration keeps deal and contact context in sync automatically
  • Durable memory on hosted Postgres so context survives restarts and deploys, not just the session
RenderPostgres (Neon / AWS) Google OAuthZoho
